System Architecture

30-source parallel pipeline.
Every source isolated, every failure contained.

Engineering Depth

The data science under the hood.

Semantic deduplication, multi-domain correlation, confidence scoring, adaptive alert triage — built without a single external data-science library.

⚡
Delta Engine
Change detection & semantic deduplication
Numeric signals: VIX (±5%), yield spreads, WTI, Brent, NatGas, unemployment, mortgage rates, USD index. Last 5 observations stored for trend extraction.

Count deltas with noise gates: thermal detections (±500), air activity (±50), conflict fatalities (±5).

Semantic dedup: content-hashes Telegram posts, normalises numbers and timestamps — kills alert fatigue from cross-channel duplicates.
// Risk direction: weighted cross-domain score const score = vixΔ * 2 + yieldΔ * 1.5 + urgentPosts * 0.8 + conflictΔ * 1.2 + thermalΔ * 0.3; direction = score > 0 ? 'risk-off' : score < 0 ? 'risk-on' : 'mixed';
🧠
LLM Integration
7 providers, raw fetch, no SDKs
A unified provider abstraction on raw fetch() — no vendor SDK, no lock-in. Single interface: complete(system, user, opts).

Sweep data is compressed to ~8KB before dispatch — 22 FRED indicators, energy, geopolitical signals, thermal counts, deltas — fitting any context budget while maximising signal density.

Trade Idea Generator
Cross-domain quantitative analysis
5–8 actionable ideas per sweep: LONG / SHORT / HEDGE / WATCH / AVOID — with ticker, confidence, rationale, risk, and time horizon. Multi-source citations required.

Rule-based fallback correlates: conflict-energy nexus, yield curve inversion, HY spread vs VIX divergence, GSCPI + PPI pipeline, and defense procurement signals.

🚨
Alert Triage
Adaptive cooldown & multi-tier escalation
Three tiers with progressive cooldown decay: 1st (0h) → 2nd within 24h (6h) → 3rd (12h) → 4th+ (24h). FLASH requires multi-domain confirmation — no single-source false triggers.
FLASH — Multi-domain confirmed
PRIORITY — 2–3 confirming signals
ROUTINE — Standard sweep update
🗄️
Memory System
Hot/cold storage with atomic writes and crash recovery
Hot memory holds 3 sweep runs in-memory, written atomically (temp → backup → rename) to prevent corruption. Cold storage archives daily JSON snapshots for historical pattern matching. The delta engine compares against this timeline to detect escalation trends — not just point-in-time spikes. Confidence scoring rewards cross-domain corroboration: a yield spread move confirmed by VIX, urgent OSINT posts, and a concurrent conflict event scores far higher than an isolated spike.
