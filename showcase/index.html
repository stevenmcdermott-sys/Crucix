The Challenge

Intelligence is scattered.
Crucix unifies it.

Global intelligence exists across dozens of fragmented public sources — satellite feeds, economic databases, conflict trackers, social signals, radiation monitors, and live market data. Each requires separate accounts, authentication, and bespoke parsers.

Analysts spend hours aggregating data that's already stale by the time it's correlated. The signal is buried in noise. The connections between domains are missed entirely.

Crucix solves this with a zero-cloud, self-hosted intelligence terminal — 27 sources queried in parallel every 15 minutes, synthesised by an LLM, and delivered as actionable insights.

Engineering Depth

The data science under the hood.

Beyond ingestion — semantic deduplication, multi-domain correlation, confidence scoring, and adaptive alert triage built without a single external data-science library.

⚡
Delta Engine
Change detection & semantic deduplication
Numeric signals tracked with configurable thresholds: VIX (±5%), yield spreads, WTI, Brent, NatGas, unemployment, mortgage rates, USD index. Last 5 observations stored for trend extraction.

Count-based metrics with noise-suppression gates: thermal detections (±500 to flag), air activity (±50), conflict fatalities (±5), urgent OSINT posts.

Semantic deduplication for Telegram content — normalises numbers, timestamps, punctuation — prevents alert fatigue from duplicate posts across channels.
// Risk direction from cross-domain signal weights const score = vixDelta * 2 + yieldSpreadDelta * 1.5 + urgentOsintPosts * 0.8 + conflictEvents * 1.2 + thermalDetections * 0.3; direction = score > 0 ? 'risk-off' : score < 0 ? 'risk-on' : 'mixed';
🧠
LLM Integration
7 providers, raw fetch, no SDKs
A unified provider abstraction built on raw fetch() — no Anthropic SDK, no OpenAI SDK. Each provider module handles auth, model defaults, and response parsing with a single interface: complete(system, user, opts).

Sweep data is compressed to ~8KB before dispatch — extracting 22 FRED indicators, energy prices, geopolitical signals, thermal counts, and delta changes — fitting within any model's context budget.

Trade Idea Generator
Cross-domain quantitative analysis
Each sweep produces 5–8 actionable trade ideas combining geopolitical, economic, and market signals. The LLM acts as a "quant analyst at a macro intelligence firm" — output is structured JSON with ticker, type, confidence, rationale, risk, and time horizon.

Without an LLM, a rule-based fallback correlates: conflict-energy nexus, yield curve inversion signals, credit-equity divergence (HY spread vs VIX), supply chain–inflation pipeline (GSCPI + PPI), and defense procurement signals.

🚨
Alert Triage System
Adaptive cooldown & multi-tier escalation
Three-tier alert system with progressive cooldown decay to prevent fatigue: 1st occurrence (0h wait) → 2nd within 24h (6h cooldown) → 3rd (12h) → 4th+ (24h). LLM-enhanced when configured, rule-based otherwise.

Cross-domain confirmation required for FLASH tier — a single spiking signal never triggers critical alerts without multi-source validation.
FLASH — Crisis-level, multi-domain confirmed
PRIORITY — Significant, 2–3 confirming signals
ROUTINE — Standard sweep update
🗄️
Persistent Memory System
Hot/cold storage with atomic writes and crash recovery
Hot memory stores the last 3 sweep outputs in-memory with atomic file writes (temp → backup → rename) to prevent data corruption on crash. Cold storage archives daily JSON snapshots for historical pattern matching. The delta engine compares against this timeline to detect escalation trends, not just point-in-time spikes.

Confidence scoring weighs cross-domain corroboration: a yield spread move confirmed by VIX, urgent OSINT posts, and a concurrent conflict event scores far higher than a single isolated data spike. This architecture eliminates noise while catching genuinely rare, correlated events.
