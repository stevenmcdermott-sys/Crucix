Engineering Depth

The data science under the hood.

⚡
Delta Engine
Semantic change detection
Numeric signals: VIX (±5%), yield spreads, WTI, Brent, NatGas, unemployment, mortgage rates. Last 5 observations stored for trend extraction.

Count gates: thermal (±500), air activity (±50), conflict fatalities (±5) — noise suppression before escalation.

Semantic dedup: content-hashes Telegram posts, normalises numbers and timestamps — eliminates cross-channel duplicates.
// Weighted cross-domain risk direction const score = vixΔ*2 + yieldΔ*1.5 + urgentPosts*0.8 + conflictΔ*1.2; direction = score > 0 ? 'risk-off' : 'risk-on';
🧠
LLM Integration
7 providers · raw fetch · no SDKs
Unified provider abstraction on raw fetch() — no vendor lock-in. Single interface: complete(system, user).

Data compressed to ~8KB before dispatch: 22 FRED indicators, energy prices, geopolitical signals, deltas — maximising signal density within any context budget.

💡
Trade Idea Generator
Cross-domain quant analysis
5–8 actionable ideas per sweep: LONG / SHORT / HEDGE / WATCH / AVOID — ticker, confidence, rationale, risk, horizon, multi-source citations.

Rule-based fallback: conflict-energy nexus, yield curve inversion, HY spread vs VIX divergence, GSCPI + PPI pipeline, defense procurement signals.

🚨
Alert Triage
Adaptive cooldown · multi-tier escalation
Progressive cooldown decay: 1st occurrence (0h) → 2nd within 24h (6h) → 3rd (12h) → 4th+ (24h). FLASH requires multi-domain confirmation — single-source spikes never trigger critical alerts.
FLASH — Multi-domain confirmed
PRIORITY — 2–3 confirming signals
ROUTINE — Standard update
🗄️
Memory System
Hot/cold storage · atomic writes · crash recovery
Hot memory: 3 sweep runs in-memory, written atomically (temp → backup → rename). Cold storage: daily JSON archives for historical pattern matching. Confidence scoring rewards cross-domain corroboration — a yield move confirmed by VIX + OSINT + conflict scores far higher than an isolated spike.
